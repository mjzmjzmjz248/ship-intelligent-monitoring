# 第一版 Demo 进度记录

依据：课程需求（仓库根目录的系统指南与告警模型需求清单）及《第一版 Demo 实施方案》（未随仓库发布）。开发环境：Linux 虚拟机（16 核 CPU、约 9 GB 内存、无 GPU、无摄像头、无声卡），Python 3.14；目标运行环境为 Windows。

## 2026-10-24 第一轮（Claude）

### 结论

方案中第 1–3 周的核心闭环已实现，并在本机跑通：

> 视频 → 人员检测 → ROI/规则 → 船端本地告警（播报）+ 截图/短视频/MD5 → 上传岸端 → 网页确警处置 → 升级通知；
> 断开船岸同步时船端照常告警，恢复后补传、不重复。

6 类告警（A1 驾驶室无人在岗、A2 值班室离岗、A3 视频设备异常、A4 终端离线、A5 AIS 异常、A6 航速违规）全部实现并验证。
所用视频是**合成视频**，船况和 AIS 是**模拟数据**，结果只证明系统流程正确，不代表真实识别效果。

### 验证结果（均为本机实际运行）

1. **自动测试**：`python -m pytest` → **42 项全部通过**。覆盖方案 10.1 的 R1–R13（规则阈值前后、重复提醒、回岗清零、恢复需持续、黑屏不计无人、停泊/遥测过期不触发、航速防抖、断流、跨日计数、船长超时只升级一次）以及岸端接口、升级通知、终端离线、船岸同步（断网补传、ACK 丢失重传、MD5 篡改拒收、重启续传、revision 顺序）。
2. **端到端走查**：`python scripts/smoke_e2e.py` 启动真实的岸端和船端进程，**21 项全部通过**（约 3 分钟）。关键数据：
   - 人员离开 10 秒后触发 A1；阈值满足→船端告警约 0.02 秒，→开始播报约 0.03 秒，→岸端收到约 0.26 秒（本机回环网络、规则等待时间不计入）。
   - 截图约 100 KB、视频约 240 KB；视频实际覆盖 9.9 秒（触发前后各约 5 秒）；下载文件 MD5 与岸端记录一致。
   - 黑屏段触发 A3（BLACK_SCREEN），且黑屏期间未误报离岗。
   - 断开同步后约 17 秒岸端判定终端离线；断网期间船端本地照常产生 A1、A5、A6，积压 24 条待上传；恢复后 1 秒内补传清空，A4 恢复，补传事件均标记“补传”，船端 5 条事件与岸端 5 条一一对应、无重复。
   - 同日第 2 次 A1 产生船长限时处置通知。
3. **离线事件评测**：`python scripts/eval_events.py ...`（逐帧回放 100 秒合成视频）
   - 驾驶室配置：A1 正检 1/1、误检 0；A3 正检 1/1、误检 0。
   - 值班室配置：A2 正检 1/1、误检 0；A3 正检 1/1、误检 0。
   - **样本只有 1 段合成视频，不能据此说明检出率或准确率。**
4. **性能（单路，CPU）**：YOLO11n 输入 640，单帧推理约 55–70 ms；按 5 次/秒运行，实际识别 5.0 次/秒。不代表 6 路 720P@15FPS 的能力。
5. **网页**：在应用内浏览器中实际登录并检查了 5 个页面：预览显示人框和 ROI；告警详情中截图可显示、视频可在浏览器播放（H.264）；确警操作写入时间线；切换 standard/demo 参数套与在画面上绘制 ROI 后，船端均自动应用新版本（设备页显示“已应用”）。

### 本轮修复的问题

- 证据可能先于事件上传，导致一次 409 重试 → 改为先写事件再生成证据。
- 上传成功后控制台仍显示旧错误 → 成功时清除。
- 程序被强制结束时正在编码的视频会一直显示“编码中” → 启动时标记为失败并写明原因（已加测试）。

### 与实施方案的差异

| 方案原写 | 实际做法 | 原因 |
| --- | --- | --- |
| Vue 3 + Vite + Element Plus | Vue 3 + Element Plus 免构建，库文件放在 `web/vendor/` | 本机无 Node；Windows 上也不用装 npm，离线可用 |
| 系统 FFmpeg | `imageio-ffmpeg` 自带的 ffmpeg | 本机无 ffmpeg；Windows 同样 pip 即可 |
| SQLModel | 标准库 `sqlite3` | 少一层依赖，行为透明 |
| pygame 播放 | Windows 用标准库 `winsound`；其他平台无声卡时只记日志并标注“未实际播放” | 虚拟机无声卡 |
| 预录中文语音 | 已生成提示音（高风险急促三声）；中文语音由 `scripts/gen_audio.py` 在 Windows 上用 pyttsx3 生成 | Linux 上没有中文离线 TTS |
| 自录实验室视频 | 用 Ultralytics 自带样例图拼出的 100 秒合成视频 + 真值 CSV | 本机无摄像头 |
| 值班室为独立场所 | 与驾驶室共用同一个船端进程，通过“切换摄像头”演示 A2 | demo 简化；正式部署应是独立终端 |
| 证据视频叠加信息 | 只有截图叠加船名/位置/时间/航速；视频保持原始画面 | 首版简化，指南 4.3.1 要求后续补齐 |
